# Batalla Cósmica — Demo web V0.3

**Prototipo jugable 1 vs 1 (persona contra bot)** del juego original de cartas espaciales. Nombre y arte provisionales.

## Abrir el juego
Abre `index.html` directamente en Chrome, Edge o Firefox. El archivo contiene todo el HTML, CSS y JavaScript; no necesita instalaciones ni conexión para jugar contra el bot.

## Reglas de la demo
- Máximo **4 cartas** en mano. En cada turno puedes jugar una o descartar entre 1 y 4 para robar reemplazos aleatorios.
- Mazo central boca abajo y descarte boca arriba; cuando se agota el mazo, se mezcla de nuevo el descarte.
- Meteoritos para atacar, escudos y lunas para proteger, reparación y cuatro tipos de planetas.
- Estrella fugaz: elige **solo uno**: atacar, proteger o transformarse en el tipo de planeta que te falte.
- En esta versión **no hay restricciones de colores**, ni multijugador por internet, ni anuncios.
- Fondo espacial y animaciones; selección de meteorito con borde dorado.

## Publicación
Esta demo está en la rama `batalla-cosmica-v03` del repositorio `frankel` para no modificar el sitio principal. Para crear un sitio independiente conviene mover estos archivos a su propio repositorio GitHub y activar Pages desde **Settings → Pages → Deploy from a branch**.
